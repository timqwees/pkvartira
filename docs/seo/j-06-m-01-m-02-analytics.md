## M-02 — заявки из органического поиска (ноябрь–март)

### Что уже настроено в коде

| Элемент | Где | Что делает |
|---|---|---|
| Счётчик Метрики на всех страницах | `public/components/head-includes.php` | Раньше был только на главной — цели не срабатывали на внутренних страницах |
| Цель `SENDFORM` | `public/components/footer.php` | Отправка формы (уже была) |
| Цель `LEAD` с параметром `source` | `public/components/footer.php` | **Новое.** Разделяет заявки: `yandex` / `google` / `referral:<домен>` / `direct` |
| Скрытые поля `utm_*`, `yclid`, `gclid`, `landing_page`, `referrer` | `public/components/head-includes.php` | Сохраняются в заявку — источник виден в письме |
| Разметка в письме «Трафик → ОРГАНИКА / РЕКЛАМА / ПРЯМОЙ ЗАХОД» | `setting/Route/Functions/TheFunction.php` | Уже была, теперь работает на всех страницах |

### Как считать

1. **Метрика** → Конверты → Цели → `LEAD` → срез по параметру `source`.
2. Фильтр по датам (ноябрь–март) и по параметру `source` = `yandex` — это заявки из органики Яндекса. Аналогично `google`.
3. CR органики = заявки из `source=yandex|google` ÷ визиты из поиска (источник «Поиск») за тот же период.
4. Данные по заявкам без Метрики — в письмах: раздел «Трафик →» содержит utm и домен реферера.

Кодовая часть подготовлена: счётчик работает на всех страницах, цели настроены, разметка источника в заявках добавлена. Остаётся выгрузка данных из кабинетов и их фиксация в отчётах.
