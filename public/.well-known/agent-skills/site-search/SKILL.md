# Site search

Ищи по сайту Проект Квартира (Проект Квартира, remont.pkvartira.ru) GET-запросом:

```
GET https://remont.pkvartira.ru/search?q={запрос}
```

Возвращает HTML с результатами: услуги (`/services/...`), статьи блога (`/blog/article/...`),
цены (`/prices`), вакансии (`/vakansii/...`). Без авторизации, без лимитов.
Карта сайта: https://remont.pkvartira.ru/sitemap.xml
