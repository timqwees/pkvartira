# Site search

Ищи по сайту Проект Квартира (ПКвартира, pkvartira.ru) GET-запросом:

```
GET https://pkvartira.ru/search?q={запрос}
```

Возвращает HTML с результатами: услуги (`/services/...`), статьи блога (`/blog/article/...`),
цены (`/prices`), вакансии (`/vakansii/...`). Без авторизации, без лимитов.
Карта сайта: https://pkvartira.ru/sitemap.xml
