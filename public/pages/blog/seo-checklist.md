# Еженедельный чеклист мониторинга SEO

**Каждый понедельник, 30 минут.**

---

## 1. Яндекс Вебмастер (10 мин)

- [ ] Новые ошибки индексации (раздел «Диагностика»)
- [ ] Изменения в ИКС (раздел «Индекс качества»)
- [ ] Новые страницы в индексе (раздел «Страницы»)
- [ ] Ошибки сканирования (раздел «Сканирование»)
- [ ] Файлы robots.txt и sitemap.xml без ошибок

## 2. Яндекс Метрика (10 мин)

- [ ] Посещаемость за неделю (сравнение с прошлой)
- [ ] Глубина просмотра по ключевым страницам (1room, novostroyka, smeta)
- [ ] % отказов по ключевым страницам
- [ ] Цели: FORM_START, SENDFORM (заявки)
- [ ] Возвраты (returning visitors) — динамика

## 3. Wordstat / Бренд-запросы (5 мин)

- [ ] `пквартира` — объём за месяц
- [ ] `проект квартира отзывы` — объём за месяц
- [ ] `pkvartira` — объём за месяц
- [ ] Новые брендовые запросы (если появились)

## 4. Конкуренты (5 мин)

- [ ] Позиции по 5 ключевым запросам (вручную или через Вебмастер)
- [ ] Новые страницы у конкурентов (если отслеживаете)

---

## Ежемесячно (1-е число)

- [ ] ИКС — динамика (цель: +20–30 за квартал)
- [ ] Отзывы на площадках: 2ГИС, Яндекс Карты, Профи.ру (цель: +5–10 в месяц)
- [ ] Бренд-запросы в Wordstat — динамика
- [ ] Внешние ссылки — новые упоминания (если отслеживаете)
- [ ] llms.txt / llms-full.txt — актуальность (при каждом релизе)
