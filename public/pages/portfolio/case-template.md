# Шаблон кейса «Смета → Факт»

**Использование:** скопировать в `public/pages/portfolio/case-{slug}/index.php`, заполнить данные.

---

## Структура кейса

### 1. Hero
- **H1:** Ремонт {тип квартиры} в {район/ЖК} — {площадь} м² за {срок}
- **Подзаголовок:** Смета → Процесс → Результат. Цена зафиксирована в договоре.

### 2. Блок «Было» (2–3 фото)
- Фото квартиры до ремонта
- Описание состояния: стены, пол, потолок, коммуникации
- Проблемы, которые нужно было решить

### 3. Блок «Смета»
- Таблица: пакет, цена за м², итого
- Состав работ (список)
- Срок по договору

### 4. Блок «Процесс» (3–5 фото)
- Этапы: демонтаж → черновые → чистовые → финальная уборка
- Фото с объекта (реальные, не стоки)
- Комментарий прораба: что было сложным

### 5. Блок «Стало» (3–5 фото)
- Фото после ремонта
- Сравнение: было → стало (если есть бок о бок)

### 6. Блок «Цена и срок»
- Смета: {сумма} ₽
- Факт: {сумма} ₽ (отклонение: {±X%})
- Срок по договору: {N} дней
- Факт: {N} дней

### 7. Отзыв клиента (если есть)
- Имя, дата, текст
- Ссылка на площадку (2ГИС/Яндекс/Профи)

### 8. Смотрите также (hub-links)
- Главная, Цены, Смета, Калькулятор, Ремонт под ключ, Отзывы, Блог

---

## Чек-лист перед публикацией

- [ ] Все фото реальные (с этого объекта)
- [ ] Смета и факт совпадают (или отклонение объяснено)
- [ ] Срок реальный (по договору)
- [ ] Нет липы: никаких «10 лет», «50+ объектов», «98%»
- [ ] Отзыв реальный (есть на площадке)
- [ ] Страница в sitemap
- [ ] Ссылается на /services/pod-klyuch и /prices
