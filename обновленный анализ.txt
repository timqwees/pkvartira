<section class="seo-section">
  <h2>Проверка robots.txt</h2>
  <p>Инструмент анализирует файл robots.txt вашего сайта, который управляет доступом поисковых роботов к страницам. Проверяются правила для всех user-agent, директивы Allow/Disallow, Crawl-delay, ссылки на Sitemap. Некорректный robots.txt может привести к деиндексации важных страниц или открытию служебных разделов.</p>
  <p>Частые ошибки в robots.txt: блокировка CSS/JS файлов (ломает рендеринг для Google), отсутствие директивы Sitemap, Allow/Disallow без начального слеша и конфликтующие правила для одного пути. Наш валидатор находит эти проблемы и показывает, какие URL заблокированы для каждого User-Agent.</p>
  <p>Всегда тестируйте изменения robots.txt перед деплоем — одна опечатка может деиндексировать весь сайт. После валидации проверьте <a href="/broken-links">битые ссылки</a>, чтобы заблокированные страницы не ссылались из активного контента. Проверьте <a href="/security">заголовки безопасности</a> для защиты чувствительных путей.</p></section>

  <h2>Часто задаваемые вопросы</h2>
  <div class="faq-list">
    <details class="faq-item"><summary>Что такое robots.txt?</summary><p>robots.txt — текстовый файл в корне сайта, указывающий поисковым роботам, какие страницы можно или нельзя индексировать. Это рекомендация, а не принудительная блокировка — недобросовестные боты могут его игнорировать.</p></details>
    <details class="faq-item"><summary>Чем robots.txt отличается от meta robots?</summary><p>robots.txt блокирует краулинг (робот не зайдёт на страницу). Meta robots (noindex) блокирует индексацию (робот зайдёт, но не добавит в индекс). Для полной блокировки нужны оба. Если robots.txt блокирует страницу, робот не увидит meta noindex.</p></details>
    <details class="faq-item"><summary>Как правильно указать Sitemap в robots.txt?</summary><p>Добавьте строку Sitemap: https://example.com/sitemap.xml в конец файла. URL должен быть абсолютным. Можно указать несколько sitemap. Это помогает роботам быстрее найти карту сайта.</p></details>
    <details class="faq-item"><summary>Что такое Crawl-delay?</summary><p>Crawl-delay — директива robots.txt, задающая паузу между запросами робота в секундах. Yandex и Bing поддерживают её. Google игнорирует Crawl-delay — скорость краулинга Google настраивается в Search Console.</p></details>
    <details class="faq-item"><summary>Какие частые ошибки в robots.txt?</summary><p>Типичные ошибки: блокировка CSS/JS файлов (мешает рендерингу), Disallow: / (блокирует весь сайт), отсутствие файла (робот считает всё разрешённым), блокировка /api/ без Allow для /api/docs, неправильный регистр User-agent.</p></details>
    <details class="faq-item"><summary>Как проверить robots.txt?</summary><p>Наш инструмент анализирует синтаксис, проверяет доступность файла, находит конфликтующие правила и предупреждает о потенциальных проблемах. Также можно использовать Google Search Console для проверки конкретных URL.</p></details>
