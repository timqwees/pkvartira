## 1. Исправление пустой страницы «Портфолио»

**Проблема:** Страница с примерами работ (портфолио) открывалась пустая — контент не отображался.

**Причина:** Элементы страницы были скрыты с помощью CSS (непрозрачность 0). Скрипт, который должен был их показывать при прокрутке, не работал.

**Решение:** Убрали специальную разметку, которая скрывала контент. Теперь все работы отображаются сразу при открытии страницы.
